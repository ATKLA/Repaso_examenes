Arquitectura

1. Modelo Vista Controlador

MVC es un patrón de diseño que divide la aplicación en 3 capas independientes. El objetivo es que cada parte haga una sola cosa: los datos son responsabilidad del Modelo, la presentación de la Vista, y la lógica de negocio del Controlador. Esto hace el código más limpio, fácil de mantener y reutilizable.

🗄️

Modelo

¿Qué hace? → Gestiona los datos
  • Conecta con la base de datos
  • Define la estructura de los datos
  • Contiene la lógica de negocio
  • No sabe nada de la Vista
🖥️

Vista

¿Qué hace? → Muestra los datos
  • Solo HTML, CSS, JS
  • Recibe datos del Controlador
  • No toma decisiones
  • Sin lógica de negocio
⚙️

Controlador

¿Qué hace? → Conecta todo
  • Recibe la petición del usuario
  • Decide qué Modelo usar
  • Pasa datos a la Vista
  • Es el intermediario
Usuario → Controlador → Modelo → Controlador → Vista → Usuario
💡 En el examen: si te preguntan qué capa hace X, piensa — ¿es datos? Modelo. ¿Es interfaz? Vista. ¿Es lógica/decisión? Controlador.
PHP

2. PHP Básico

PHP es un lenguaje de servidor: el código se ejecuta en el servidor y devuelve HTML al navegador. Todo el código va entre <?php y ?>. Las variables siempre empiezan por $.

2.1 Variables y Arrays

Una variable guarda un valor. Un array guarda varios valores. El array asociativo usa clave→valor, como un diccionario.

php — variables_arrays.php
<?php
// Variables — tipo automático según el valor asignado
$nombre = "Laura";     // string
$edad   = 25;          // int
$precio = 19.99;       // float
$activo = true;        // bool

// Array INDEXADO — acceso por posición numérica (0, 1, 2...)
$numeros = [1, 2, 3];
echo $numeros[0];      // 1

// Array ASOCIATIVO — acceso por clave de texto
$persona = [
    'nombre' => 'Laura',
    'edad'   => 25
];
echo $persona['nombre'];  // Laura

// Concatenar cadenas con punto .
echo "Hola, " . $nombre . "!";  // Hola, Laura!

// Interpolación dentro de comillas dobles
echo "Hola, $nombre!";          // Hola, Laura!
?>

2.2 Estructuras de Control

Permiten tomar decisiones (if) y repetir acciones (foreach). El foreach es el más habitual en PHP para recorrer resultados de base de datos.

php — estructuras.php
<?php
// IF / ELSE — toma decisiones
if ($edad >= 18) {
    echo "Mayor de edad";
} elseif ($edad >= 16) {
    echo "Casi mayor";
} else {
    echo "Menor de edad";
}

// FOREACH — recorre cada elemento del array
// Útil para arrays de resultados de BD
foreach ($numeros as $numero) {
    echo $numero;           // imprime 1, 2, 3
}

// FOREACH con clave => valor
// Útil para arrays asociativos
foreach ($persona as $clave => $valor) {
    echo "$clave: $valor";  // nombre: Laura / edad: 25
}

// FOR clásico — cuando necesitas el índice
for ($i = 0; $i < 3; $i++) {
    echo $i;  // 0, 1, 2
}
?>

2.3 Funciones

Una función agrupa código reutilizable. Le das un nombre, puede recibir parámetros y devolver un resultado con return. PHP 7+ permite declarar los tipos de los parámetros.

php — funciones.php
<?php
// Función básica — recibe parámetro, devuelve string
function saludar($nombre) {
    return "Hola, " . $nombre;
}
echo saludar("Laura");  // Hola, Laura

// Función tipada (PHP 7+)
// int $a, int $b → solo acepta enteros
// : int → solo puede devolver entero
function sumar(int $a, int $b): int {
    return $a + $b;
}
echo sumar(3, 4);  // 7

// Función con parámetro por defecto
function despedir($nombre = "amigo") {
    return "Hasta luego, " . $nombre;
}
echo despedir();         // Hasta luego, amigo
echo despedir("Laura");  // Hasta luego, Laura
?>
PDO

3. Conexión PDO

PDO (PHP Data Objects) es la forma moderna de conectar PHP con bases de datos. Funciona con MySQL, PostgreSQL, SQLite y más. Su ventaja principal es que usa consultas preparadas, que protegen contra inyección SQL.

Flujo de trabajo PDO — de memoria

1
new PDO() — crea la conexión con los datos del servidor y la base de datos.
2
prepare($sql) — prepara la consulta SQL con marcadores de posición (:param) en lugar de los valores reales.
3
execute([...]) — ejecuta la consulta sustituyendo los marcadores por los valores reales de forma segura.
4
fetchAll() / fetch() — obtiene los resultados como array. Solo para SELECT.

3.1 Conexión básica

La conexión se hace en un bloque try/catch. Si algo falla, PDO lanza una excepción que puedes capturar en lugar de mostrar un error feo.

php — conexion.php
<?php
$host   = 'localhost';   // servidor donde está MySQL
$dbname = 'biblioteca';  // nombre de la base de datos
$user   = 'root';
$pass   = '';

try {
    // DSN = Data Source Name: tipo:host=...;dbname=...
    $pdo = new PDO(
        "mysql:host=$host;dbname=$dbname;charset=utf8",
        $user,
        $pass
    );

    // ERRMODE_EXCEPTION: lanza excepciones en vez de errores silenciosos
    $pdo->setAttribute(PDO::ATTR_ERRMODE, PDO::ERRMODE_EXCEPTION);

    echo "¡Conexión exitosa!";

} catch (PDOException $e) {
    // Si algo falla, muestra el error y para la ejecución
    die("Error de conexión: " . $e->getMessage());
}
?>

3.2 SELECT — consultar datos

Para leer datos. Si la consulta no tiene condiciones, usa query(). Si tiene condiciones con variables, siempre usa prepare() + execute().

php — select.php
<?php
// SELECT simple — sin parámetros, se puede usar query()
$stmt   = $pdo->query("SELECT * FROM libros");
$libros = $stmt->fetchAll(PDO::FETCH_ASSOC);
// FETCH_ASSOC → devuelve array con nombres de columna como claves

foreach ($libros as $libro) {
    echo $libro['titulo'] . " - " . $libro['autor'];
}

// SELECT con WHERE — SIEMPRE consulta preparada
// :autor es un marcador de posición, no el valor real
$sql  = "SELECT * FROM libros WHERE autor = :autor";
$stmt = $pdo->prepare($sql);
$stmt->execute(['autor' => 'García Márquez']); // aquí va el valor real
$resultado = $stmt->fetchAll(PDO::FETCH_ASSOC);

// Obtener solo una fila
$stmt = $pdo->prepare("SELECT * FROM libros WHERE id = :id");
$stmt->execute(['id' => 1]);
$libro = $stmt->fetch(PDO::FETCH_ASSOC);  // fetch() → solo una fila
?>
🔒 ¿Por qué prepare + execute? Si concatenaras la variable directamente en el SQL ("WHERE autor = '$autor'"), un usuario podría inyectar código SQL malicioso. Con :param, PDO escapa automáticamente el valor.

3.3 INSERT — insertar datos

Añade una nueva fila. Con lastInsertId() obtienes el ID autogenerado del registro que acabas de insertar.

php — insert.php
<?php
$sql = "INSERT INTO libros (titulo, autor, precio)
        VALUES (:titulo, :autor, :precio)";

$stmt = $pdo->prepare($sql);
$stmt->execute([
    'titulo' => 'Cien años de soledad',
    'autor'  => 'García Márquez',
    'precio' => 25.50
]);

// Obtiene el ID del registro recién insertado
echo "Libro creado con ID: " . $pdo->lastInsertId();
?>

3.4 UPDATE — actualizar datos

Modifica filas existentes. Con rowCount() sabes cuántas filas se han actualizado. Siempre incluye WHERE o actualizarás TODA la tabla.

php — update.php
<?php
$sql  = "UPDATE libros SET precio = :precio WHERE id = :id";
$stmt = $pdo->prepare($sql);
$stmt->execute(['precio' => 29.99, 'id' => 1]);

echo "Filas actualizadas: " . $stmt->rowCount();
// rowCount() → número de filas afectadas por la consulta
?>

3.5 DELETE — eliminar datos

Elimina filas. ¡Cuidado! Sin WHERE borra toda la tabla.

php — delete.php
<?php
$sql  = "DELETE FROM libros WHERE id = :id";
$stmt = $pdo->prepare($sql);
$stmt->execute(['id' => 5]);

echo "Filas eliminadas: " . $stmt->rowCount();
?>

3.6 Clase Database (buena práctica)

En proyectos reales, la conexión se separa en su propio archivo para no repetirla en cada script. Se crea una clase con un método que devuelve el objeto $pdo.

config/database.php
<?php
class Database {
    // Datos de conexión como propiedades privadas
    private $host     = 'localhost';
    private $dbname   = 'biblioteca';
    private $username = 'root';
    private $password = '';

    public function getConnection() {
        try {
            $pdo = new PDO(
                "mysql:host={$this->host};dbname={$this->dbname};charset=utf8",
                $this->username,
                $this->password
            );
            $pdo->setAttribute(PDO::ATTR_ERRMODE, PDO::ERRMODE_EXCEPTION);
            return $pdo;  // devuelve el objeto PDO listo para usar
        } catch (PDOException $e) {
            echo "Error: " . $e->getMessage();
            return null;
        }
    }
}
?>
php — usar_database.php
<?php
require_once 'config/database.php';  // carga la clase

$database = new Database();
$pdo      = $database->getConnection();  // obtiene la conexión

// A partir de aquí, $pdo está listo
$stmt = $pdo->query("SELECT * FROM libros");
?>
Laravel

4. Laravel — CRUD Completo

Laravel es un framework PHP que implementa MVC automáticamente. En lugar de escribir SQL a mano, usas clases (Eloquent ORM) que representan las tablas. Sigue el principio de convención sobre configuración: si respetas los nombres, Laravel hace el resto solo.

📌 Regla de nombres clave: el Modelo es singular (Libro), la tabla y las rutas son plural (libros). Laravel lo detecta automáticamente.

4.1 Crear Proyecto

Composer descarga Laravel y crea la estructura de carpetas. El archivo .env contiene la configuración sensible (credenciales de BD, etc.).

bash — terminal
# Crea un nuevo proyecto llamado 'biblioteca'
composer create-project laravel/laravel biblioteca

cd biblioteca  # entra en la carpeta del proyecto

# Editar .env con los datos de tu base de datos:
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=biblioteca
DB_USERNAME=root
DB_PASSWORD=

# Arrancar el servidor local (http://localhost:8000)
php artisan serve

4.2 Migración — crear la tabla

Una migración es un archivo PHP que define la estructura de una tabla. En vez de crear la tabla a mano en MySQL, la defines en código y Laravel la crea con php artisan migrate. Así el esquema queda versionado.

bash
# Crear el archivo de migración
php artisan make:migration create_libros_table

# Ejecutar todas las migraciones pendientes (crea las tablas)
php artisan migrate
database/migrations/xxxx_create_libros_table.php
<?php
use Illuminate\Database\Migrations\Migration;
use Illuminate\Database\Schema\Blueprint;
use Illuminate\Support\Facades\Schema;

return new class extends Migration
{
    // up() → se ejecuta al hacer migrate (CREA la tabla)
    public function up(): void
    {
        Schema::create('libros', function (Blueprint $table) {
            $table->id();                            // INT, PK, autoincremental
            $table->string('titulo');                // VARCHAR(255)
            $table->string('autor');                 // VARCHAR(255)
            $table->decimal('precio', 8, 2);         // DECIMAL: 8 dígitos, 2 decimales
            $table->integer('stock');                // INT
            $table->text('descripcion')->nullable(); // TEXT, acepta NULL
            $table->timestamps();                    // crea created_at y updated_at
        });
    }

    // down() → se ejecuta al hacer migrate:rollback (ELIMINA la tabla)
    public function down(): void
    {
        Schema::dropIfExists('libros');
    }
};
?>
Método BlueprintTipo SQL equivalenteCuándo usarlo
$table->id()BIGINT PK AUTO_INCREMENTSiempre como primera columna
->string('campo')VARCHAR(255)Textos cortos: nombre, título, email
->text('campo')TEXTTextos largos: descripción, contenido
->integer('campo')INTNúmeros enteros: stock, edad
->decimal('campo', 8, 2)DECIMAL(8,2)Precios, importes con decimales
->boolean('campo')TINYINT(1)Verdadero/falso: activo, publicado
->timestamps()DATETIME created_at + updated_atSiempre al final si quieres auditoría
->nullable()Modificador: permite NULLCampos opcionales

4.3 Modelo — representar la tabla

El Modelo es una clase PHP que representa la tabla en la base de datos. Cada instancia del modelo es una fila. Eloquent ORM te permite hacer consultas sin escribir SQL.

bash
php artisan make:model Libro
app/Models/Libro.php
<?php
namespace App\Models;

use Illuminate\Database\Eloquent\Model;

class Libro extends Model
{
    // $table → nombre de la tabla (opcional si sigue la convención: Libro → libros)
    protected $table = 'libros';

    // $fillable → campos que se pueden asignar con create() o update()
    // OBLIGATORIO para usar asignación masiva (evita vulnerabilidades)
    protected $fillable = [
        'titulo',
        'autor',
        'precio',
        'stock',
        'descripcion'
    ];

    // Ejemplos de uso del modelo (no van en el archivo, son para referencia):
    // Libro::all()              → SELECT * FROM libros
    // Libro::find(1)            → SELECT * FROM libros WHERE id = 1
    // Libro::findOrFail(1)      → igual pero lanza error 404 si no existe
    // Libro::where('autor','X') → SELECT * FROM libros WHERE autor = 'X'
    // Libro::create([...])      → INSERT INTO libros (...)
}
?>
⚡ $fillable es obligatorio si usas Libro::create() o $libro->update(). Sin él, Laravel rechaza la asignación masiva por seguridad.

4.4 Controlador — la lógica de cada acción

El Controlador maneja cada acción del usuario. Con --resource, Artisan genera automáticamente los 7 métodos CRUD estándar.

bash
php artisan make:controller LibroController --resource
app/Http/Controllers/LibroController.php
<?php
namespace App\Http\Controllers;

use App\Models\Libro;
use Illuminate\Http\Request;

class LibroController extends Controller
{
    // index() → GET /libros — muestra la lista completa
    public function index()
    {
        $libros = Libro::all();  // obtiene todos los libros
        return view('libros.index', compact('libros'));
        // compact('libros') → pasa $libros a la vista
    }

    // create() → GET /libros/create — muestra el formulario de creación
    public function create()
    {
        return view('libros.create');
    }

    // store() → POST /libros — guarda el nuevo libro
    public function store(Request $request)
    {
        // validate() comprueba los datos. Si falla, redirige con errores.
        $request->validate([
            'titulo' => 'required|max:255',  // obligatorio, máx 255 chars
            'autor'  => 'required',
            'precio' => 'required|numeric',  // obligatorio, debe ser número
            'stock'  => 'required|integer',
        ]);

        Libro::create($request->only(
            'titulo', 'autor', 'precio', 'stock', 'descripcion'
        ));

        // redirect()->route() redirige a la ruta por su nombre
        // with('success',...) pasa un mensaje flash a la vista
        return redirect()->route('libros.index')
                         ->with('success', 'Libro creado correctamente');
    }

    // show() → GET /libros/{id} — muestra un libro específico
    public function show($id)
    {
        $libro = Libro::findOrFail($id);  // 404 si no existe
        return view('libros.show', compact('libro'));
    }

    // edit() → GET /libros/{id}/edit — muestra el formulario de edición
    public function edit($id)
    {
        $libro = Libro::findOrFail($id);
        return view('libros.edit', compact('libro'));
    }

    // update() → PUT /libros/{id} — guarda los cambios
    public function update(Request $request, $id)
    {
        $request->validate([
            'titulo' => 'required|max:255',
            'autor'  => 'required',
            'precio' => 'required|numeric',
            'stock'  => 'required|integer',
        ]);

        $libro = Libro::findOrFail($id);
        $libro->update($request->only(
            'titulo', 'autor', 'precio', 'stock', 'descripcion'
        ));

        return redirect()->route('libros.index')
                         ->with('success', 'Libro actualizado');
    }

    // destroy() → DELETE /libros/{id} — elimina el libro
    public function destroy($id)
    {
        Libro::findOrFail($id)->delete();
        return redirect()->route('libros.index')
                         ->with('success', 'Libro eliminado');
    }
}
?>

MongoDB

5. MongoDB — CRUD Completo

MongoDB es una base de datos NoSQL orientada a documentos. En vez de tablas con filas, tienes colecciones con documentos (objetos JSON). Cada documento puede tener campos distintos. No hay esquema fijo.

🧭 Esta sección muestra la sintaxis en los dos formatos que debes conocer: MongoDB Compass / Shell (lo que practicas en clase con db.coleccion.método()) y PHP con la librería oficial.

5.1 Conexión en PHP

bash — instalar librería
composer require mongodb/mongodb
php — conexion_mongo.php
<?php
require 'vendor/autoload.php';
use MongoDB\Client;

// Conectar al servidor MongoDB (puerto por defecto: 27017)
$cliente   = new Client("mongodb://localhost:27017");

// Seleccionar la base de datos
$db        = $cliente->biblioteca;

// Seleccionar la colección (equivale a tabla en SQL)
$coleccion = $db->libros;
?>

5.2 INSERT — insertar documentos

Los documentos son arrays asociativos PHP / objetos JSON. Pueden contener arrays anidados dentro. MongoDB genera automáticamente el _id único.

MongoDB Compass / Shell
// Insertar uno
db.libros.insertOne({
  titulo: "Don Quijote",
  autor: "Cervantes",
  precio: 15.99,
  categorias: ["Clásico", "Novela"]
})

// Insertar varios
db.libros.insertMany([
  { titulo: "La Regenta", autor: "Clarín",  precio: 18.50 },
  { titulo: "El árbol",   autor: "Baroja",  precio: 12.00 }
])
php — insert_mongo.php
<?php
// insertOne() → inserta un documento
$resultado = $coleccion->insertOne([
    'titulo'     => 'Don Quijote',
    'autor'      => 'Cervantes',
    'precio'     => 15.99,
    'categorias' => ['Clásico', 'Novela']  // array dentro del documento
]);
echo "ID insertado: " . $resultado->getInsertedId();

// insertMany() → inserta varios documentos de una vez
$resultado = $coleccion->insertMany([
    ['titulo' => 'La Regenta', 'autor' => 'Clarín', 'precio' => 18.50],
    ['titulo' => 'El árbol',   'autor' => 'Baroja', 'precio' => 12.00],
]);
echo "Insertados: " . count($resultado->getInsertedIds());
?>

5.3 FIND — buscar documentos

find() devuelve un cursor (iterable). findOne() devuelve solo el primer resultado o null. El primer parámetro es el filtro.

MongoDB Compass / Shell
// Todos los documentos
db.libros.find({})

// Filtro exacto
db.libros.find({ autor: "Cervantes" })

// Con operador: precio > 15
db.libros.find({ precio: { $gt: 15 } })

// Rango: precio entre 10 y 20
db.libros.find({ precio: { $gte: 10, $lte: 20 } })

// Solo uno
db.libros.findOne({ titulo: "Don Quijote" })
php — find_mongo.php
<?php
// Todos los documentos
$libros = $coleccion->find([]);
foreach ($libros as $libro) {
    echo $libro['titulo'];
}

// Filtro exacto (como WHERE autor = 'Cervantes')
$libros = $coleccion->find(['autor' => 'Cervantes']);

// Con operador: precio mayor que 15
$libros = $coleccion->find(['precio' => ['$gt' => 15]]);

// Rango: precio entre 10 y 20
$libros = $coleccion->find([
    'precio' => ['$gte' => 10, '$lte' => 20]
]);

// findOne() → devuelve solo un documento (o null)
$libro = $coleccion->findOne(['titulo' => 'Don Quijote']);
echo $libro['autor'];  // Cervantes
?>

5.4 Operadores de comparación

En MongoDB los operadores siempre llevan $ delante. Son la clave para hacer filtros avanzados.

OperadorSignificadoCompass / ShellPHP
$eqIgual a{ precio: { $eq: 20 } }['precio' => ['$eq' => 20]]
$gtMayor que (>){ precio: { $gt: 15 } }['precio' => ['$gt' => 15]]
$gteMayor o igual (≥){ precio: { $gte: 15 } }['precio' => ['$gte' => 15]]
$ltMenor que (<){ stock: { $lt: 10 } }['stock' => ['$lt' => 10]]
$lteMenor o igual (≤){ stock: { $lte: 10 } }['stock' => ['$lte' => 10]]
$neDistinto de (≠){ autor: { $ne: "Cervantes" } }['autor' => ['$ne' => 'Cervantes']]
$inEstá en la lista{ autor: { $in: ["Cervantes","Clarín"] } }['autor' => ['$in' => ['Cervantes','Clarín']]]

5.5 UPDATE — actualizar documentos

El primer parámetro es el filtro (qué documentos actualizar). El segundo es el operador de actualización. $set cambia campos, $inc incrementa, $push añade a arrays.

MongoDB Compass / Shell
// Actualizar uno ($set cambia solo los campos indicados)
db.libros.updateOne(
  { titulo: "Don Quijote" },           // filtro
  { $set: { precio: 19.99 } }          // cambio
)

// Actualizar varios
db.libros.updateMany(
  { autor: "Cervantes" },
  { $set: { precio: 20.00 } }
)

// Incrementar con $inc (suma al valor actual)
db.libros.updateMany(
  {},                                   // {} = todos los documentos
  { $inc: { stock: 5 } }               // suma 5 al stock de cada uno
)

// Añadir elemento a un array con $push
db.libros.updateOne(
  { titulo: "Don Quijote" },
  { $push: { categorias: "Bestseller" } }
)
php — update_mongo.php
<?php
// updateOne() — actualiza el primer documento que coincide
$coleccion->updateOne(
    ['titulo' => 'Don Quijote'],      // filtro
    ['$set' => ['precio' => 19.99]]  // operador + cambio
);

// updateMany() — actualiza todos los que coinciden
$coleccion->updateMany(
    ['autor' => 'Cervantes'],
    ['$set' => ['precio' => 20.00]]
);

// $inc — incrementa un número
$coleccion->updateMany(
    [],                          // sin filtro = todos
    ['$inc' => ['stock' => 5]]   // suma 5 al campo stock
);

// $push — añade un elemento a un array existente
$coleccion->updateOne(
    ['titulo' => 'Don Quijote'],
    ['$push' => ['categorias' => 'Bestseller']]
);
?>

5.6 DELETE — eliminar documentos

MongoDB Compass / Shell
db.libros.deleteOne({ titulo: "Don Quijote" })
db.libros.deleteMany({ precio: { $lt: 10 } })
db.libros.deleteMany({})  // elimina todos los documentos
php — delete_mongo.php
<?php
// Eliminar UNO (el primero que coincida)
$coleccion->deleteOne(['titulo' => 'Don Quijote']);

// Eliminar VARIOS (todos los que coincidan)
$coleccion->deleteMany(['precio' => ['$lt' => 10]]);

// Eliminar TODOS los documentos de la colección
$coleccion->deleteMany([]);
?>
⚠️ Cuidado: deleteMany([]) elimina TODOS los documentos. El filtro vacío {} coincide con todo.

5.7 Opciones avanzadas — Sort, Limit, Skip, Projection

Se pasan como segundo parámetro en find(), tanto en Compass como en PHP.

MongoDB Compass / Shell
// Ordenar: 1 = ascendente, -1 = descendente
db.libros.find({}).sort({ precio: 1 })
db.libros.find({}).sort({ precio: -1 })

// Limitar resultados
db.libros.find({}).limit(5)

// Paginación: saltar 10, mostrar 5
db.libros.find({}).skip(10).limit(5)

// Proyección: qué campos devolver (1=incluir, 0=excluir)
db.libros.find({}, { titulo: 1, precio: 1, _id: 0 })
php — opciones_mongo.php
<?php
// sort → ordenar. 1 = asc, -1 = desc
$libros = $coleccion->find([], ['sort' => ['precio' => 1]]);

// limit → máximo de resultados
$libros = $coleccion->find([], ['limit' => 5]);

// skip + limit → paginación (página 3 de 5 en 5)
$libros = $coleccion->find([], ['skip' => 10, 'limit' => 5]);

// projection → solo devuelve los campos indicados
// 1 = incluir, 0 = excluir (_id se excluye si no se incluye)
$libros = $coleccion->find([], [
    'projection' => [
        'titulo' => 1,
        'precio' => 1,
        '_id'    => 0   // excluir el _id
    ]
]);
?>
